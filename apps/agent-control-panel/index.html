How this panel works

  • Commands are project skills in .claude/skills/; each one launches its workflow script from .claude/workflows/ (audit-sessions.js, bug-hunt.js, spec-to-plan.js).
  • Workflows never write to your files — bug-hunt and audit-sessions are read-only; spec-to-plan only returns a plan. Fixes happen only when you ask.
  • Reports respect known constraints: generous timeouts, workers: 1, and no webServer are deliberate and never flagged.
